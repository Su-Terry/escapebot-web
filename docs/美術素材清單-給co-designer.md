# 美術素材清單（Cat Got Your Words）

> **這份檔案的用途**：供「美術 session」當上下文。co-designer（設計師）以正常使用者身分跟一個 session 對話、推進美術；session 讀這份檔案進入狀況,再跟 co-designer 聊。
> **真相源 / 維護**：repo `/docs`。**進度更新由作者手動回寫**——co-designer 不碰 repo / git / 檔案,session 也不自動改;聊出結論後由作者更新這份。與 repo 不一致時以 repo 為準。

---

## ⚠️ session 開工前必讀（兩條護欄）

跟 co-designer 聊美術時,最容易順著聊就踩這兩條。先記住:

1. **「埋住貓」還沒拍板,別當定案去設計**。分享卡 C 版想要「滿地包子埋住貓」的現場縮圖,但現在 3D 縱深架構下**包子圍不住貓**(貓在遠處深度平面、包子過去會被透視縮小,畫面長不出來)。這是空間架構問題、記在 BACKLOG「Q-埋貓」,**待作者拍板**。在拍板前,不要照「埋住貓」去定構圖或畫對應素材。這類要作者決定的事,session 記下來帶回給作者,不替作者拍。

2. **小尺寸 icon 不要走 AI 生 pixel path**。試過多版,AI 憑空生 pixel SVG 在 18px 這種尺寸**必糊**。icon 的 pixel 化要 co-designer 用真 pixel 工具手畫。別再建議「讓 AI 補個 icon 試試」。

## 風格基準（已定,照這個補）

- **Pixel art（像素風）+ 暖色調**——配合療癒系的包子與貓。
- 北極星:**順眼 + 「貓=LLM 化身」概念立得住**。不追求華麗或複雜,「看起來順眼」即可。
- 核心畫面語意:貓吃進包子、吐出包子,視覺上就是「LLM 在運作」。包子是「對話的物理化身」(現在是療癒系叉燒包;未來不同主題世界觀可換成不同「對話物件」)。

co-designer 接手不是從零定調,是照這個基準補。

## 素材清單

> 狀態圖例:⬜ 未開始　🔄 進行中　✅ 已交付。**由作者回寫。**

### 1. 貓的動畫 frames　⬜
最核心、最缺(每局每回合都看到,核心循環的視覺爆點):
- **咬 / 嚼 / 吐**:現在只用 cat-idle ↔ cat-hit 兩張圖換圖 + 縮放模擬「嚼」,沒有真的咀嚼幀。
- **滿足表情**:吃完的反應。
- **貓尾巴動作**:射歪的包子,貓甩尾巴掃回(程式接現有「飛回彈弓 returnToLaunch」結構,差素材)。

> 行為層另有「貓走走停停 idle 小動作」規劃(讓貓從介面變活角色),偏程式/行為設計、不一定是新 sprite,做到時再談。

### 2. 包子 sprite　⬜
- **黃金包**(線索)、**腐爛包**(weird moment)——現在只有普通包一種,分類視覺還沒有。
- 普通包已有,不用補。

### 3. 場景背景　⬜
- **手繪背景**取代現在程式畫的漸層天空 + 暖土色地面 + 接地陰影。
- 渲染已分圖層(bgLayer / groundLayer / shadowLayer),**換素材不用動邏輯**,照圖層出圖即可。

### 4. UI icon（指標 / 手套切換）　⬜
- 現用 lucide-react 線條 icon(MousePointer2 + Grab,18px,清楚可辨)。
- pixel 風統一要 co-designer 真 pixel 工具手畫(見上方護欄 2)。

### 不用補（記錄）
- **meow-scared sprite**:砸貓 / scared 沒納入核心循環(現行是「丟給貓吃」不是「砸貓」),暫時無用。

## 優先級建議（非硬性,可跟 co-designer 重新排）

照「核心循環爆點優先」:**貓的咬/嚼/吐 frames** 收益最大(每回合都看到),其次**包子分類 sprite**(接 weird moment 系統),**場景背景**和 **icon pixel 化**屬精緻度提升、可後。這是直覺排序,實際節奏與分工跟 co-designer 一起定。
